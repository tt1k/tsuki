## Tsuki Translate Release Note
**0.0.2**

Tsuki Translate 0.0.2 focuses on stronger local note workflows and better reading output quality.
This update adds local cache/export capabilities, online note-to-PDF generation, and rendering experience fixes.

- **SQLite3 local cache and export support**  
  Notes can now be cached locally via `sqlite3`, with structured export support for easier backup and migration.

- **Online upload of local notes to generate personalized PDF**  
  You can upload local note data and generate a personalized PDF file online for sharing and long-term study review.

- **Rendering and usability issue fixes**  
  Fixed several rendering and interaction issues to improve overall reading and translation flow quality.

---

Thanks for using Tsuki Translate.
We will keep improving translation quality and reading workflow in upcoming releases.
