## Tsuki Translate Release Note
**0.0.1**

Tsuki Translate is now live.
Powered by six core capabilities, it unifies capture, translation, and retention into a single, continuous experience.

- **One-tap invoke, speak and translate**  
  Enter translation mode instantly with minimal context switching so you can stay focused.

- **Tsuki CLI cross-app instant translation**  
  Jump into translation from any app in seconds and make translation part of your daily workflow.

- **Lemma, pronunciation, senses, examples in one view**  
  Results go beyond correctness by showing key lexical signals in a single structured panel.

- **Token highlight + furigana on example lines**  
  Read long sentences with clearer segmentation and faster comprehension.

- **Dark / Light theme switching**  
  Freely match visual mode to your environment for comfort and sustained focus.

- **Automatic translation archive for learning**  
  Each successful translation is automatically saved as daily `NOTE-day.md` and `NOTE-night.md` entries with paired screenshots, reducing manual organization work.
